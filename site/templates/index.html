Terminal coding agent · v0.1.4

tm is a coding agent for your terminal. Talk to it live. When a task can run without you, hand it to a background worker as a ticket. Workers submit evidence; you accept it, send it back, or retry it. Every step is an event in a log you can replay.

03

The gate

Workers cannot approve their own work, and you decide which actions need a person first.

Accept, reject and retry are human-only; the server answers 403 to an agent that tries. Inside a run, an oversight.toml at your repo root lists the action classes that stop and ask a human before they dispatch.

Since 0.1.4 that includes shell.string: a sh -c "…" command is a whole program, so passing a per-command allow-list is not enough. Redirections, expansions and quoting tricks are invisible to it. List the class and a person sees the line first.

A cloned repo cannot loosen its own gate. Its oversight.toml is ignored until you run tm trust, and any later edit asks again.
