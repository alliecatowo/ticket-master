Chat with the agent. Ticket the rest.

Ticketmaster (tm) is a coding agent for your terminal. Talk to it live, and when a task can run without you, hand it to a background worker as a ticket. Workers submit evidence; you accept, reject or retry. Every step lands in an event-sourced log you can replay.

What it is

Most agents make you babysit one long chat. tm splits the work: a fast interactive agent for the thinking, and a crew of background workers for anything you can spec in a sentence.

ChatAsk, explore, edit in the TUI. @ completes files, ! runs shell.
Dispatch/bg fix the pagination bug or the dispatch box turns a sentence into a ticket.
WorkA worker leases the ticket, edits in isolation, runs the checks.
SubmitIt submits a summary with evidence: test reports, diffs.
DecideYou accept, send it back with a reason, or retry with guidance.

Key features

Built on the idea that tools should be as intelligent as the agents using them. Read the thesis →

▶

Interactive TUI

A chat-first terminal UI with slash commands, history search, plan / ask / auto modes, and a tickets screen laid out like a task inbox.

☰

Ticket-powered workers

Background workers run tickets under leases and budgets, with retries, escalation and a worktree option for isolated runs.

✓

Human-gated outcomes

Accept, reject and retry are human-only. The server answers 403 to an agent that tries them. Workers cannot approve their own work.

↻

Event-sourced and replayable

Every change is an event in a durable log. Record a run to a cassette and replay it offline, or fork a ticket at any event.

⚲

Resolved context

Context is resolved up front, then symbol-aware and semantic search finds the rest, so the first turn already has what it needs.

⚙

Any provider, any editor

21 provider backends, an MCP server for Claude Code, an ACP agent for Zed, a VS Code extension, and a typed TypeScript client.

Install

One binary. Prebuilt for macOS arm64 today; build from source on Linux.

Release tarball

curl -fLO {{ config.extra.github_repo }}/releases/download/v0.1.0/tm-aarch64-apple-darwin.tar.gz
tar -xzf tm-aarch64-apple-darwin.tar.gz
./tm-aarch64-apple-darwin/tm init

From source

cargo install --git {{ config.extra.github_repo }}.git tm-cli --locked
tm init && tm

You need one configured provider, for example ANTHROPIC_API_KEY. Full install guide, providers.
